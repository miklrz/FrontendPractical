# Фронтенд-разработка РТУ МИРЭА

## Описание  
Этот репозиторий был создан в рамках курса "Фронтенд-разработка" в РТУ МИРЭА. В нем содержатся 4 учебных проекта, разработанных на языках HTML, CSS и JavaScript. Проекты выполнены в соответствии с заданиями курса "Фронтенд-разработчик" от Яндекс.Практикума .  

Каждый проект демонстрирует освоение ключевых навыков фронтенд-разработки, включая верстку, стилизацию, интерактивность и работу с DOM.  

## Содержание  

1. **Проект 1: Научиться учиться: вёрстка**  
   *Описание*: Одностраничный сайт.  
   *Навыки*: Флексбокс-вёрстка.  
   *Технологии*: HTML, CSS, JavaScript.  

2. **Проект 2: Научиться учиться: анимация, шрифты, фреймы**  
   *Описание*: Одностраничный сайт.  
   *Навыки*: Анимации и трансформации, организация файлов по БЭМ.  
   *Технологии*: HTML, CSS, JavaScript.  

3. **Проект 3: Путешествие по России**  
   *Описание*: Адаптивная страница про путешествия по стране.  
   *Навыки*: Адаптивная верстка.  
   *Технологии*: HTML, CSS, JavaScript.  

4. **Проект 4: Mesto — интерактивная страница**  
   *Описание*: Интерактивная страница.  
   *Навыки*: JS, DOM.  
   *Технологии*: HTML, CSS, JavaScript.  

5. **Проект 5: Mesto. Валидация форм и инфраструктура**  
   *Описание*: Интерактивная страница.  
   *Навыки*: JS, DOM, Валидация.  
   *Технологии*: HTML, CSS, JavaScript.  

6. **Проект 6: Взаимодействие с сервером и GitHub Pages**  
   *Описание*: Mesto — интерактивная страница, взаимодействие с сервером.  
   *Навыки*: JS, DOM, GitHub Pages, API, Promise.  
   *Технологии*: HTML, CSS, JavaScript.  

## Автор  

Проект разработан студентом РТУ МИРЭА в рамках курса "Фронтенд-разработка".
